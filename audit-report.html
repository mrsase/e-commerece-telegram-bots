prisma/schema.prisma — No unique constraint on (userId, state='ACTIVE')
Open
Race ConditionsSchema
No DB-level unique constraint prevents multiple ACTIVE carts per user. addItemToCart in cart-utils.ts uses findFirst + conditional create inside a transaction, but SQLite's serializable isolation would still allow a second concurrent transaction to also see no cart and insert. Fix requires a Prisma migration to add a partial unique index + application-level PerUserMutex (already in place for interactive handlers, missing for command-based ones — now fixed). Remaining risk: no DB constraint.
